# Автоматизация бизнес-процессов Инженерной школы
Веб-система для сопровождения проектной деятельности школьников.

Система предназначена для преподавателей и администраторов и должна объединить работу со списками школьников, школами и классами, проектными командами, занятиями, посещаемостью, историей работы над проектами и отчётностью.
